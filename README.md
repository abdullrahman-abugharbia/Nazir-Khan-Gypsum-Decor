# Master Nazir Khan – Gypsum & Gypsum Board Decor

**معلم نزير خان · ديكورات الجبس وجبسم بورد**

Arabic (RTL) one-page site for a gypsum and gypsum-board contractor in Ar Rawdah, Riyadh: suspended ceilings, partitions, TV walls and finishing.

- Gallery of the crew's own job photos and a frame strength-test video
- Scroll-scrubbed 3D illustration of how a suspended ceiling is built (rendered in Blender)
- Call and WhatsApp buttons (0557582241) and a map of the work location

Plain HTML, CSS and JavaScript — no build step. Open `index.html`, or serve the folder:

```bash
python -m http.server 8000
```
